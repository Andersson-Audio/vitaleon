# Building Vitaleon

Vitaleon is built with Akai's MPC Plugin Builder SDK. The SDK compiles the 32-bit and 64-bit ARM libraries for the MPC and a native library for tests on the build computer.

## 1. Get the SDK at the right commit and patch it

```
git clone https://github.com/inmusic-software/mpc-plugin-builder-sdk.git
cd mpc-plugin-builder-sdk
git checkout febd2ca5bd9eb16c4a412837196e145566bc981b
```

Put this repository at `plugins/Vitaleon` inside the SDK folder, then apply the patch:

```
git clone https://github.com/Andersson-Audio/vitaleon.git plugins/Vitaleon
git apply plugins/Vitaleon/sdk-patches/sdk-local-changes.patch
```

The patch adds hooks to the SDK framework that Vitaleon needs (state restore as one transaction, a program list that can change, parameter writes without callbacks). [sdk-patches/README.md](sdk-patches/README.md) explains each change. Without it Vitaleon does not compile.

Follow the SDK's own `GETTING_STARTED.md` to install its toolchain.

## 2. Build

From the SDK folder:

```
python tools/build.py plugins/Vitaleon
```

The result is `plugins/Vitaleon/build/Andersson Audio - VST - Vitaleon/`, ready to copy into `VST2 Plugins` on a drive. The build takes about ten minutes.

## 3. Tests

All from `plugins/Vitaleon`. They need a C++17 `clang++` or `g++` and Python 3 with Pillow.

| Command | What it checks |
|---|---|
| `python tests/run_full_checks.py` | The plugin through its exported entry point: import, banks, library, state save and restore, graphs, matrix, CPU guard |
| `python tools/check_surface.py` and the other `tools/check_*.py` | The generated skin: bindings, step counts, touch targets, duplicates, no baked run-time lists |

## Content

A build made from this repository has an empty `Content` folder apart from short notes: the factory wavetables and sounds of the official release are not part of the source and may not be redistributed (see [FACTORY-CONTENT-LICENSE.txt](FACTORY-CONTENT-LICENSE.txt)). The plugin works without them; it starts with one sound named Init and loads any Vital preset, bank or wavetable you add.

## The skin

`skins/TUI.json` and its images are generated by `tools/generate_surface.py`. The generator reads `build/params.json`, which a build writes. So: build once, run the generator, run the `check_*.py` tools, build again. Do not run the generator while a build is compiling; it also writes `src/SurfaceMap.h`.

## Parameter rules

The plugin has 1856 parameters. Projects store them by ID. Never change the ID, order or meaning of an existing parameter and never change the plugin's unique ID. New parameters are appended at the end.
